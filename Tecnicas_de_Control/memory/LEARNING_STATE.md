# Estado de aprendizaje

Este archivo registra dominio demostrado, no cantidad de material leído ni explicaciones recibidas.

## Escala de evidencia

- `0 — no evaluado`: todavía no existe evidencia.
- `1 — reconocimiento`: identifica conceptos con apoyo.
- `2 — explicación`: puede explicarlos con sus propias palabras.
- `3 — aplicación guiada`: resuelve con alguna pista o corrección.
- `4 — aplicación autónoma`: resuelve y comprueba un problema nuevo sin ayuda relevante.

Una valoración declarada por el usuario puede registrarse como percepción, pero no sustituye una evidencia práctica.

## Reglas de actualización

- Registrar archivo, páginas o ejercicio usado como evidencia.
- No subir de nivel únicamente porque se haya generado un resumen.
- Bajar o matizar el nivel si una comprobación posterior muestra una laguna importante.
- Mantener un único siguiente paso concreto por tema siempre que sea posible.
