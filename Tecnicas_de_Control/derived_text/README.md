# Texto derivado

Esta carpeta contiene únicamente texto auxiliar obtenido de fuentes originales escaneadas o sin capa textual.

Cada derivado debe indicar:

- ruta y SHA-256 del original;
- páginas procesadas;
- método y herramienta;
- fecha de generación;
- limitaciones o fragmentos dudosos.

El texto derivado sirve para búsqueda y apoyo a la lectura. Nunca sustituye al documento original ni se considera una transcripción perfecta sin revisión.

La subcarpeta `scanned_sources/` se creará al generar el primer derivado; no se mantiene vacía por adelantado.
